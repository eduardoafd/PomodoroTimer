# 🍅 PomodoroTimer

A simple and fun desktop application to help you manage your productivity using the Pomodoro Technique.


---

## 🧠 Features

- ⏱️ Customizable Pomodoro timers (work, short break, long break)
- 🔔 System tray integration for easy access and notifications
- 📊 Tracking of completed Pomodoros
- 🧩 Fun and intuitive UI design
- 🛠️ Lightweight and fully offline

---

## 🖥️ Installation

### Prerequisites

- Python 3.8+

### Clone the Repository

```bash
git clone https://github.com/eduardoafd/PomodoroTimer.git
cd PomodoroTimer
```

### Install Dependencies
```bash
pip install -r requirement.txt
```

### Generate/Use the Executable
An .exe file is provided which can be used without the installation of the dependencies, as a simple Windows application. You can also generate your own executable using PyInstaller by running the generate_exe.py script.
